# TreeChat

**让思考自由生长。** 面向 DeepSeek Harness 的文本锚点聊天分支插件。

在对话中选中一个术语、一句话或一段文字，点击“分支讨论”，在旁边继续讨论。每个分支继承创建位置之前的对话背景，随后独立发展；分支还能继续分叉，也能提升为独立会话。

## 当前版本

`0.3.0-dev.8`，目标宿主为 **DSH 0.2.1-alpha.2 / macOS ARM64**。已完成原生主会话、子分支首问与追问、孙分支的真实 DeepSeek 模型验证，并通过落盘历史隔离、模型选择顺序、原文跳转、提升和刷新恢复检查。

- **直接在 DSH 主聊天界面生效**：选中文字创建分支，使用原生右侧面板讨论。
- 未提升的 TreeChat 子分支从原生工作区列表、计数和搜索结果中隐藏；提升后显示。
- 分支面板采用原生色调、蓝黑文字和从子会话输入框底部向上延伸的静态柔和渐变，右上角提供提升与分支树图标，悬停或键盘聚焦即时显示操作名称。
- 从已保存的用户消息或已完成的 AI 回复选区创建分支。
- 按消息的精确事件边界调用原生 `session/fork`，继承背景，后续历史互不回写。
- 多级分支树、原文蓝色下划线、悬停蓝色底纹、点击原文打开分支、返回来源。
- 分支首问中的原文采用灰色引用块；继承历史默认隐藏，首问前的居中开关可原地展开／收起主会话上下文，并保持阅读位置，背景始终参与模型请求。
- 原文锚点悬停时显示改过的分支名称。
- 点击分支标题可原地改名；Enter 或勾号保存，Esc 或叉号取消。名称同步到原生会话、路径和分支树，刷新后保留。
- 提升任意分支为独立会话，保持原来的会话 ID、父子关系和历史。
- 显式继承父会话当前的模型提供方、模型和推理等级，避免原生 fork 回落到全局默认路由。
- 首问通过 DSH 原生 composer 的发送接口提交；后续使用原生聊天组件、流式回复与工具交互。
- 分支关系保存在当前浏览器；刷新后恢复记录与浏览位置。

## 安装

在源码目录运行：

```sh
npm run build
npm test
```

安装到已有 DSH Web profile：

```sh
dsh plugin --profile web add /absolute/path/to/dsh-treechat
dsh web
```

也可以执行 `npm pack`，再通过上述命令安装生成的 `.tgz` 包。没有全局 `dsh` 命令时，可使用 `npx @deepseek-ai/dsh@0.2.1-alpha.2` 替换命令中的 `dsh`。

启动后直接使用 **DSH 原聊天界面**。正文旁的分支标记可恢复已有讨论；分支面板右上角的 TreeChat 图标打开分支树。分支树以主会话为纵向主轴，沿连线展示尚未提升的子分支与嵌套关系，支持 Control＋滚轮以鼠标为中心缩放、拖动空白处平移，以及缩放按钮、重置和适应窗口；提升后的会话及其子树在对应主会话中查看。树图返回会恢复打开前的分支和阅读位置。日常聊天界面只保留分支导航和提升操作。全局侧栏与主会话标题栏保持精简。

1. 打开或新建一个对话。
2. 在消息正文中选中文字，点击“分支讨论”。
3. 输入第一个问题，Enter 发送、Shift+Enter 换行；中文输入法选词时保留正常确认行为。发送时创建真实分支，取消空草稿直接返回。
4. 在分支内可以继续选择文字，创建下一层分支。
5. 点击原文旁的分支按钮恢复讨论；点击“返回原文”定位来源。
6. 点击标题右侧的圆圈上箭头（悬停提示“提升为主会话”），在 DSH 主聊天区域打开同一会话并更新标题，同时将它加入原生工作区列表。

主界面的分支使用 DSH 原生右侧面板：宽窗口可并排显示；窄窗口沿用宿主的全屏面板，通过“返回原文”回到主对话。

## 上下文规则

选中文字用于定位讨论主题；AI 的背景继承到**选区所在的整条消息结束处**，并非截断到选区的某个 token。助手回复使用最终 `assistant/message` 的事件序号，避免误用流式开始位置而丢掉回答正文。

父对话随后新增的消息不会自动进入已有分支，子分支也不会自动回写父对话。首个分支问题附带原文引用；后续对话直接使用原生消息流。

## 存储与当前边界

- **聊天正文**：由 DSH 持久化。
- **文本锚点、标题、提升状态、TreeChat 浏览位置**：保存在当前浏览器、当前服务地址的本地存储中。跨设备同步尚未实现；当前界面暂不提供手动导入导出入口。
- 原生工作区过滤通过 `src/sidebar.cjs` 中针对 **DSH 0.2.1-alpha.2** 的兼容适配实现：包装 SlotCore 中的 `WorkspaceBrowser` 组件入口，为它提供过滤后的列表、工作区和搜索结果。完整会话目录与落盘数据保持可用，停用插件后恢复宿主列表。升级宿主时需要重新验证此入口。
- 隐藏状态依赖当前浏览器的分支关系记录；迁移浏览器或端口需一并迁移本地关系记录。普通原生 fork 沿用宿主行为。
- 对话历史独立不等于工作目录隔离：原生 fork 可以共享文件和工具环境。
- 选区限定在一条消息内；流式生成尚未保存的文本、工具面板和跨消息选区不作为首版锚点。
- 如果原文排版改变，定位使用原文引用及其前后文字重新匹配；遇到歧义时返回消息，不猜测具体位置。
- 尚不包含分支合并、自动总结或多 Agent 调度。

## 独立开发实例

开发启动器使用独立 profile 和端口，不修改已有 DSH  配置。需要指向本机已安装的 DSH 包目录：

```sh
DSH_RUNTIME=/path/to/dsh-runtime/node_modules/@deepseek-ai/dsh \
TREECHAT_ENV_FILE=/path/to/your-existing.env \
node scripts/dev.mjs
```

默认端口 `3081`，可以用 `PORT` 修改。当前原生界面验证实例使用 `3082`。`TREECHAT_ENV_FILE` 可省略，凭据也可从环境或该独立 profile 的原生设置提供。启动终端会显示带本地认证令牌的访问地址。启动器关闭开发目录的递归热更新，改动后需要重新构建、重启和刷新。

可选 `TREECHAT_MOCK=1` 启用明确标记的本地测试回复；该模块只在 test-support 中，不进入可安装的插件包。

## 验证

```sh
npm run build
DSH_TEST_ROOT=/path/to/dsh-runtime npm test
```

包括锚点定位与歧义处理、准确分叉边界、嵌套关系、提升身份、导入校验、持久化失败保护、多窗口覆盖保护，以及与真实 DSH SlotCore 的注册兼容检查。不设置 `DSH_TEST_ROOT` 时仅跳过宿主契约检查。

`test-support/audit-history.mjs` 可对独立开发实例中带测试标记的父/子/孙会话做只读历史审计。验证范围见 `VERIFICATION.md`。

## 代码结构

- `src/send.cjs`：父会话模型快照、分支模型确认、原生 composer 发送。
- `src/core.cjs`：锚点、关系、导入校验、版本化本地存储。
- `src/sidebar.cjs`：原生工作区列表与搜索过滤兼容适配。
- `src/keyboard.cjs`：Enter、Shift+Enter 和输入法组合输入判断。
- `src/client.cjs`、`src/style.css`：原生聊天集成与分支界面。
- `scripts/build.mjs`：生成并校验客户端脚本语法。
- `scripts/dev.mjs`：启动独立开发 profile。
- `lib/client.js`：可直接安装的生成产物。

模型请求与聊天持久化复用 DSH 原生能力，宿主安装文件保持原样。


## 手动重启当前预览

若任务执行环境无法管理预览进程，在用户自己的 macOS 终端运行：

```sh
node /absolute/path/to/dsh-treechat/scripts/restart-preview.mjs
```

脚本沿用 `.runtime/native-home` 和 3082 端口，先核对占用端口的程序确实为当前 TreeChat 开发实例，再发送 SIGTERM、重新启动，并打印访问链接。现有 profile 设置和会话目录会保留；新日志不进入交付包。`--check` 检查运行时路径、版本及当前预览使用的 `DEEPSEEK_API_KEY` 来源。实际重启也会先做凭据检查，再检查进程归属和关闭旧服务。启动器读取环境、显式 `TREECHAT_ENV_FILE`、当前 profile 凭据存储及项目/profile 的 `.env`；输出只显示来源。凭据预检覆盖当前 DeepSeek 官方路由的默认凭据引用，成功表示配置存在；模型连通性由实际发送验证。
